# Testando modelos

Para testar o modelos execute o script que na pasta `Scripts` chamado `diabetes_diagnose.py`. Já existe um exemplo dentro do script, mas, você pode alterar o valores.

# Gerar graficos

Para gerar os gráficos, execute(separadamente) os scripts `graphic_model1.py` e `graphic_model2.py`. Será gerado uma imagem com os graficos.

> cria a pasta `img/` dentro da pasta `data/`
